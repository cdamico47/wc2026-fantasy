How to Play
Everything you need to set up your league, run the draft, and compete all tournament long.
🏆 What Is WC 2026 Fantasy League?

WC 2026 Fantasy League is a private group fantasy game for the FIFA World Cup 2026. Your group holds a snake draft where each player picks real World Cup teams. As those teams play matches, your teams earn fantasy points. The player with the most points at the end of the tournament wins.

⚽ 48 teams · 104 matches · Groups → Round of 32 → Quarters → Semis → Final · Live scoring activates June 11
⚙️ Commissioner: Setting Up Your League
1
Create a new league
Click ⚡ Leagues in the header → New League → Create League. Enter a league name and set your Commissioner PIN. A unique 8-character League Code will be generated.
2
Share the League Code
Send the code (e.g. WC26ABCD) to all players. They'll enter it to join and select their slot from the roster you set up.
3
Register players and set the draft time
In the Commissioner tab, set player names, choose the number of players (2–12), set a draft date & time, and configure the pick timer.
4
Launch the draft
Click Save & Go to Draft, then Start Draft. The snake draft begins — all connected players see picks update in real time.
👤 Players: Joining a League
1
Get the League Code
Your commissioner will share an 8-character code via group chat, Discord, or text.
2
Join the league
Click ⚡ Leagues → New League → Join League. Enter the code and select your player slot from the roster.
3
Set up your team
Go to My Team to set your fantasy team name, avatar, team color, and trash talk message. Optionally set a personal PIN to protect your settings.
🎯 The Snake Draft
1
Order is randomized
The commissioner can randomize or manually set the order. Round 1 goes 1→N, Round 2 goes N→1 (snake), and so on until all 48 teams are drafted.
2
Pick when it's your turn
A timer counts down. Click any available team to draft it. If time runs out, a team is auto-picked for you.
3
All 48 teams get picked
If the count doesn't divide evenly, remaining teams go to the Undrafted pool — they still earn milestone bonuses for Group Stage finishes.
💡 The last few picks can surprise you — strong Group Stage records earn milestone bonuses worth picking deliberately.
🔒 PINs and Security
1
Commissioner PIN
Set when creating the league. Protects league settings, player management, and draft control. Only the commissioner should know this.
2
Player PIN (optional)
Set in the My Team edit panel under Security. Prevents others from editing your team name, avatar, and color. Leave blank for no protection.
3
Remembered per device
Once you log in on a device, you won't be asked again. On a new device or cleared browser, re-enter your code and PIN once to restore access.
